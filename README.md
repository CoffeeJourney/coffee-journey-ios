# Coffee Journey ☕

Coffee Journey est une application iOS développée dans le cadre du troisième challenge de l’Advanced Program.

L’application permet aux festivaliers de découvrir les ateliers autour du café, de consulter les places disponibles, d’effectuer des réservations et de gérer leurs réservations.

## Technologies

- Swift
- SwiftUI
- MVVM
- API REST Vapor
- MySQL
